# Contraband Marketplace

> The master Claude Code plugin marketplace for Branded Mayhem Collective's [Contraband](https://contraband.brandedmayhem.com) lineup. Five plugins, one marketplace, smoother bundle UX.

## Who should use this repo

You received an invitation to this repo because you bought the **Full Mayhem Stack** (the $647 bundle) on Contraband. The bundle gives you access to all 5 plugin repos plus this catalog so you can install everything from one place.

If you bought a single plugin instead, you don't need this repo — add that plugin's own repo as a marketplace and install from there. See your `/thanks` page for instructions.

## Install (Full Mayhem Stack buyers)

In Claude Code, after accepting all 6 GitHub invites:

```text
/plugin marketplace add Branded-Mayhem-Collective-LLC/contraband-marketplace
/plugin install brandprint-engine@contraband
/plugin install content-creative-lab@contraband
/plugin install seo-visibility-toolkit@contraband
/plugin install conversion-architecture@contraband
/plugin install sales-accelerator@contraband
```

Verify with `/plugin list` — you should see 5 plugins enabled, totaling 28 skills.

## Updates

When any individual plugin ships an update, refresh the catalog and pull:

```text

/plugin update brandprint-engine
```

(Or `/plugin update --all` to update everything at once.)
